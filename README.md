A chess engine in 4 KB of Python (make.fun tiny-chess-01 entry): 0x88 board, negamax with alpha-beta and quiescence, MVV-LVA + killer move ordering, piece-square evaluation, iterative deepening to a fixed 50,000-node budget. Deterministic, no clock, no model calls.

## Run it

```sh
MAKEFUN_ENV_URL=$MAKEFUN_ENV_URL python3 main.py
```
